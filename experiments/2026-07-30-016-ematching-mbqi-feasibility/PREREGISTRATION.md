# Preregistration: E-matching and model-counterexample instantiation

Bead: `E_Rust_Port-9jt.6.6`

Date frozen: 2026-07-30

## Question

On equality-free, function-free EPR clauses, does syntactic trigger matching
produce a smaller useful set of replayable ground instances than either
bounded complete clausification or model-counterexample instantiation?

This is a fragment-scoped feasibility study. It does not authorize a
production quantifier engine, a new default schedule, or a dependency on Z3.

## Source boundary

The architecture is derived from the pinned Z3 source in this repository:

- `z3/src/smt/smt_quantifier.cpp` registers unary and multipatterns with the
  matcher, queues matches as ground terms become relevant, rematches lazy
  patterns, and invokes MBQI during model checking; and
- `z3/src/smt/smt_model_finder.cpp` constructs per-variable instantiation sets,
  fixes candidate models, and adds constraints at restarts.

The prototype deliberately excludes equality, positive-arity functions,
interpreted predicates, sorts, nested quantifiers, and model projection. The
finite Herbrand universe is exactly the constants present in each CNF problem,
or one synthetic constant when none is present. Function-free matching
terminates, so duplicate matches and fixed-point rounds are measured instead
of claiming to reproduce Z3's behavior on potentially infinite term algebras.

The model-counterexample treatment is a clean-room rerun of the bounded
Inst-Gen-style loop from
`experiments/2026-07-30-008-instgen-epr-prototype/`. That completed experiment
is prior evidence, not a tunable training set.

## Frozen corpus

Use the 29-problem, treatment-blind corpus recorded in
`experiments/2026-07-30-008-instgen-epr-prototype/corpus.jsonl`. It contains
14 expected SAT and 15 expected UNSAT problems from seven EPR families. Source
hashes, partitions, and train/validation/test repetition policy remain
unchanged: train runs once and validation/test run twice, for 47 coordinates.

Add five hand cases only for mechanism and mutation coverage:

1. a ground contradiction;
2. a unary trigger chain ending in a contradiction;
3. a satisfiable unary trigger chain;
4. a two-pattern join ending in a contradiction; and
5. an incomplete-trigger case whose counterexample is not generated by the
   selected trigger fixed point.

Hand cases do not count toward advancement. No result-dependent corpus
replacement is permitted.

## Common abstraction and budgets

Every treatment starts with one stable instance per non-tautological source
clause, substituting the lexicographically first domain constant for every
variable. This is the same initial abstraction used by Experiment 008 and
provides a common ground-term seed. Ground clauses are canonicalized and
deduplicated while retaining one source-clause substitution as ancestry.

Each treatment receives four wall seconds, a hard ceiling of 100,000 unique
ground clauses, and a deterministic ceiling of 250,000 enumerated
substitutions or complete trigger matches. Clausification and E-matching
reserve the final 250 milliseconds for their one abstraction solve. Proof
production and independent checking occur outside that search budget. All
methods use the same pinned CaDiCaL 3.0.1 adapter, atom order,
source-clause order, constant order, and substitution order.

## Frozen treatments

1. **clausify** enumerates source substitutions in stable order. If enumeration
   finishes, a SAT result is complete. If a prefix is UNSAT, that result is
   sound; a satisfiable incomplete prefix is UNKNOWN.
2. **ematch** infers one deterministic pattern per source clause. Prefer the
   first literal atom containing every clause variable. Otherwise form a
   greedy multipattern by repeatedly choosing the first atom covering the
   largest number of uncovered variables. Match predicate applications
   against the ground atoms present at the start of each round, join bindings,
   add the resulting source instances, and repeat until a fixed point or
   resource limit. A ground-subset UNSAT result is sound. A satisfiable
   fixed point is reported SAT only when exhaustive evaluation of the
   CaDiCaL model over every source substitution succeeds; otherwise it is
   UNKNOWN.
3. **mbqi** repeatedly solves the current ground abstraction and adds, in
   stable source/substitution order, at most 64 instances falsified by the
   candidate model. UNSAT is sound. SAT requires an exhaustive
   counterexample-free scan. Each refinement records the candidate model,
   the prior abstraction size, and the added instance indices.

No treatment receives instances produced by another treatment. A hybrid is
not evaluated because Experiment 008 already found no added solve after
exchanging 4,353 model-guided instances with saturation.

## Metrics

For every coordinate and treatment record:

- status and termination reason;
- wall, user, system, SAT-solver, and peak-RSS measurements;
- SAT calls, refinement iterations, and enumerated substitutions;
- generated and unique ground-clause counts;
- complete-grounding fraction;
- DRAT proof size and checker time when UNSAT; and
- canonical instance and semantic hashes.

For E-matching additionally record inferred unary/multipattern sizes, rounds,
candidate matches, duplicate substitutions, duplicate ground clauses,
newly relevant atoms, fixed-point completion, and the first ungenerated model
counterexample when one exists. These counts are the trigger-loop evidence.

## Correctness and falsification gates

All applicable gates must pass before performance is interpreted:

1. every retained instance independently replays as the recorded substitution
   of its original quantified source clause;
2. E-matching ancestry independently replays round by round from the prior
   ground-atom database and the frozen trigger inference rule;
3. every logged MBQI refinement model satisfies the prior abstraction and
   falsifies every instance attributed to that refinement;
4. every UNSAT claim has a DRAT proof accepted by `drat-trim`;
5. every SAT claim survives exhaustive finite Herbrand-model checking;
6. terminal statuses agree with the corpus expectation and hand oracle;
7. the two held-out repetitions have identical semantic hashes; and
8. mutations to a substitution, ground clause, trigger binding, refinement
   model, DIMACS clause, and DRAT proof are rejected.

The run is invalid on any correctness failure or polarity disagreement.

## Decision

The result is **prototype-supported** only if all correctness gates pass and
E-matching:

- adds at least one reproducible verified held-out solve over `mbqi`, or
- retains all reproducible verified MBQI held-out solves while using at most
  half as many ground instances in aggregate and no more than 1.5 times the
  median common-solve wall time.

It is **clausification-dominant** if bounded clausification has every verified
held-out E-matching solve, E-matching adds none over MBQI, and E-matching does
not satisfy the aggregate instance-reduction alternative. It is **defer**
otherwise and **stop** on a correctness failure.

Even a prototype-supported result remains experiment-only. Production work
would require a typed term index, equality-aware matching, restart and
cancellation semantics, proof-object integration, and a real portfolio
comparison against Umlaut saturation.
