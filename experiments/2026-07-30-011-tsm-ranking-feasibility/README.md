# TSM ranking feasibility

This experiment follows
[`2026-07-29-018-tsm-learning-baseline`](../2026-07-29-018-tsm-learning-baseline/)
for Bead `E_Rust_Port-9jt.3.9`.

It first measures the production TSM path with phase-isolated native and
Callgrind workloads. A bounded ownership/index optimization is eligible only
when the profile attributes enough cost to a semantics-preserving removable
operation. Candidate-blind held-out label collection is conditional on the
optimized ranking and common-work gates in
[`PREREGISTRATION.md`](PREREGISTRATION.md).

Run `profile.py` only on the repository's Ubuntu runner. Large raw profiles
belong below
`.artifacts/experiments/2026-07-30-011-tsm-ranking-feasibility/`.
